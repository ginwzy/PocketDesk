# Mac 文件侧栏

聊天顶部的文件按钮打开同一个侧栏，只有“文件浏览”和“Diff”两个标签。点击聊天里的文件变更或工具补丁，直接打开这个侧栏的 Diff 标签。窄窗口从右侧覆盖一部分聊天，宽窗口并排显示；关闭侧栏后继续原来的聊天和草稿。

## 文件浏览

从当前会话的工作目录开始，按需读取当前层级。点击文件夹进入、点击文件预览；图片内嵌显示，文本最多读取前 256 KiB，超出时明确提示。文件预览提供外部打开入口，不修改磁盘内容。图片超过 8 MiB 时提示外部打开。

目录列表只渲染可见行；超过 100 项时出现名称筛选。目录请求使用 `counts=0`，不为每个子文件夹额外扫描、统计内容；原有文件管理页面保持默认统计行为。工作区相对目录和“此电脑”中的绝对目录都复用现有工作区接口及路径检查。

## Diff

使用固定的统一差异视图，显示增删行、少量上下文和已有行号。没有模式、搜索、字号、换行或跳转工具栏；长差异直接滚动。点击返回箭头可回到变更文件列表。

来源保持明确：

- 从顶部直接进入 Diff，读取当前工作目录的未提交改动；非 Git 目录读取本会话记录的改动。
- 从聊天变更进入，读取选中轮次通过 `ref` 保存的差异。
- 从工具进入，展示工具提交的补丁或写入内容；没有原始行号时不生成虚构行号。
- 文件浏览始终读取磁盘当前文件，不将其视作历史全文快照。

## 性能边界与验证

聊天卡片最多展示 8 个文件。侧栏文件列表按 44px 固定行高渲染可见范围；不递归预取子目录、不批量读取文件差异。差异解析在 Worker 中进行，随滚动最多渲染 160 行。切换文件、标签或会话时取消请求并终止旧 Worker，同时检查代次以丢弃迟到响应。

每个侧栏缓存最多 4 个差异，按 UTF-16 估算总计不超过 8 MiB，最多保留 100 个文件的滚动位置；关闭侧栏释放缓存。单份差异超过 8 Mi 个 UTF-16 代码单元或 150,000 行时停止预览，单行最多展示 12,000 个代码单元，截断时明确提示。请求期限为 45 秒、Worker 单次任务期限为 10 秒，失败可原地重试。

文件清单仍由现有接口完整传输；本次没有服务端文件清单分页或历史全文快照。已移除原先用于语法着色的 Prism 依赖以及左右配对、行内匹配和搜索实现。

```sh
node --test server/internal/httpapi/web_tests/change-worker.test.cjs
python3 -m playwright install chromium webkit
python3 scripts/test-mac-changes.py --server /absolute/path/to/pocketdesk --browser webkit
python3 scripts/test-mac-changes.py --server /absolute/path/to/pocketdesk --browser chromium
```

浏览器脚本自动建立并清理独立数据目录、工作区、端口和服务，不使用正式实例、外部文件打开器或系统剪贴板。可用 `--executable` 指定 Chromium 程序、`--screenshots /tmp/pd-sidebar` 保存截图。

覆盖两个标签、共用侧栏入口、10,000 项真实目录和变更清单、10,000 文件工具补丁、单文件 50,000 行差异的直接滚动、文件夹导航、文本／空文件／图片／大文件、相对及绝对会话目录、真实 Git 差异、缓存、迟到响应、原地重试、Worker 释放、草稿保留及超限提示。Chromium 记录超过 50ms 的主线程长任务；WebKit 不提供该指标。
