# Mac 文件变更查看

Mac 管理界面使用统一的只读查看区。消息中的本轮变更卡片和工具补丁都可进入，工具参数和原始执行结果仍保留独立入口。

## 数据含义

- **本轮保存的差异**通过会话及 `ref` 读取已保存的 patch，不重新计算当前工作区。
- **工具提交的补丁／写入内容**只表示工具输入，不证明操作已完整落盘。没有原始行号时不生成虚构行号。
- **打开当前文件**明确读取磁盘上的当前版本，可能包含后续修改。没有历史全文或二进制快照时不伪造历史预览。
- 此版本提供代码差异阅读；Markdown 排版预览、网页运行预览及历史图片对比不在本次范围内。

## 性能边界

- 聊天卡片最多展示 8 个文件，其余通过查看区访问。
- 查看区文件列表按可见范围渲染，每行固定 48px；筛选仅处理路径索引。
- 只读取当前选中文件，不预取整批文件。切换／关闭取消 HTTP 请求并终止旧 Worker，同时检查请求代次，防止不遵守取消的迟到响应覆盖当前选择。
- 每个查看区至多缓存 4 个文件的原始差异，按 UTF-16 字符估算不超过 8 MiB；阅读位置至多保留 100 个文件。关闭查看区清理缓存。
- 工具输入解析缓存最多 8 项，估算上限 8 MiB；切换会话时释放。
- 每次只显示 160 行，解析、搜索和语法着色在独立 Worker 中完成。一次只处理一个渲染请求，并保留最新待处理请求，避免连续输入积压任务。
- 单份差异超过 8 Mi 个 UTF-16 代码单元或 150,000 行时停止渲染，允许复制原始差异。单行预览最多 12,000 个代码单元并明确提示折叠；语法着色只处理不超过 2,000 个代码单元的行，其余使用纯文本。
- Worker 单次任务有 10 秒期限；超时可复制完整差异或重试。
- 文件清单仍由现有事件接口完整传输；本次没有增加服务端文件清单分页或历史全文快照。

## 验证

解析契约测试无需浏览器或额外 npm 依赖：

```sh
node --test server/internal/httpapi/web_tests/change-worker.test.cjs
```

浏览器联调需要已编译的电脑端程序、Playwright Python 和对应浏览器。脚本自动建立独立数据目录、工作区、端口及测试记录，退出后关闭服务并清理；不会使用正式实例或系统剪贴板。

```sh
python3 -m playwright install chromium webkit
python3 scripts/test-mac-changes.py --server /absolute/path/to/pocketdesk --browser webkit
python3 scripts/test-mac-changes.py --server /absolute/path/to/pocketdesk --browser chromium
```

可传 `--executable` 指定 Chromium 程序，或用 `--screenshots /tmp/pd-mac-changes` 保存截图。

场景包含：10,000 文件清单、10,000 文件工具补丁、单文件 50,000 行差异、按需请求、列表／代码渲染量、文件筛选（含 Mac Unicode 文件名）、搜索尾部、缓存回访与淘汰、忽略取消的迟到响应、失败重试、草稿保留、二进制／删除文件、无行号工具片段、左右视图、跨行复制、长行横向滚动、换行对齐、面板宽度、深色主题、超限提示与完整复制及 Worker 释放。Chromium 同时记录超过 50ms 的主线程长任务；WebKit 不提供该项指标。
